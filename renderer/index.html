  • ความเสี่ยงต่อไม้ ≤ ค่าเพดานที่ตั้ง (อัตโนมัติ 2–10% • default 2%) — ล็อตคำนวณให้อยู่ในเพดานเสมอ
  • RR ต่ำกว่าพื้น 1.0 = ปฏิเสธ
  • ล็อตต่ำกว่า 0.01 = ปฏิเสธ (ทุนเล็ก + SL กว้างเจอบ่อย — ตั้งใจให้เป็นแบบนี้)
  • สัญญาณ/คำสั่งจริงรวมกันนับโควตา + คูลดาวน์สัญญาณเดิม
  • โหมดเข้ม: สวนมติสภา / ไม่มีมติ = ไม่อนุญาตเข้าไม้

ข้อควรระวัง

  • แอปนี้เป็นผู้ช่วยวิเคราะห์ — ไม่ยิงออร์เดอร์เองอัตโนมัติ ส่งไม้จริงได้เฉพาะเมื่อคุณเปิดสวิตช์ + ยืนยัน 2 ชั้นเท่านั้น
  • อ่านข่าวเศรษฐกิจ (Fed, NFP, CPI) ก่อนเทรดสาย (session) สำคัญเป็นอย่างยิ่ง
  • XAUUSD เคลื่อนแรง — SL ที่ระบบให้คือเส้นตาย อย่าขยับออกไป
  • ล็อตแนะนำคำนวณจากสัญญาณ 100 ออนซ์/ล็อต ตรวจ spec โบรกเกอร์ของคุณด้วย

กลยุทธ์ แก้/เพิ่มได้

วิธีเพิ่ม plugin กลยุทธ์ของคุณเอง

  1. กด "เปิดโฟลเดอร์ plugins ของผม" → สร้างไฟล์ my-strategy.js
  2. วางโครงตามด้านล่าง แล้วกด "โหลดใหม่"
module.exports = {
  id: 'my-strategy',
  name: 'กลยุทธ์ของผม',
  description: 'อธิบายสั้น ๆ',
  strategy({ analysis, candles, price, ind }) {
    // analysis.bias = 'bull'|'bear'|'neutral'
    // candles.M5 / M15 / H1 / M1 = แท่งเทียน {t,o,h,l,c,v}
    // ind = ตัวชี้วัด (ema/rsi/atr/bollinger/swings...)
    // return { side:'buy', sl: ต้องมี, tp, confidence: 0-100, reason:'' }
    return null; // ไม่มีโอกาส
  }
};

กฎความเสี่ยงจะกรองสัญญาณจากทุก plugin เสมอ — ใส่ SL ไม่ถูก = ถูกทิ้งทันที ระบบไม่ล้มแม้ plugin ผิดพลาด

ติดตั้ง EA Bridge อัตโนมัติ

คู่มือติดตั้ง EA Bridge หลังติดตั้งไฟล์แล้ว

  1. เปิด MetaTrader 5 → กด F4 เปิด MetaEditor → ใน Navigator คลิกขวา Experts → Refresh เพื่อให้ไฟล์โผล่ (อยู่แถว GoldSignal → JsonBridgeEA.mq5)
  2. ดับเบิลคลิกไฟล์ → กด Compile (F7) → ต้องขึ้น "0 errors, 0 warnings"
  3. กลับ MT5 → ลาก EA JsonBridgeEA ไปวางบนชาร์ตทอง (XAUUSD/GOLD สัญลักษณ์ไหนก็ได้) — ถ้าแค่ดูสัญญาณ ไม่ต้องเปิด AutoTrading (จำเป็นเฉพาะเมื่อจะส่งไม้จริงจากแอป + ตั้ง AllowOrders = true)
  4. รอ 5–10 วินาที กลับมาแท็บนี้ สถานะจะเปลี่ยนเป็นเขียว "เชื่อมต่อ MT5 แล้ว"

หาก MetaEditor ไม่เห็นไฟล์ก็ชี้ไฟล์ที่ ~/Downloads/JsonBridgeEA.mq5 (กดปุ่มติดตั้งอัตโนมัติจะสำรองให้ที่นี่เสมอ) หรือกด "เลือกไฟล์ goldsignal_bridge.json เอง" ภายหลัง

แอปจะหาไฟล์ bridge ในโฟลเดอร์ MT5 ของคุณเองอัตโนมัติ ถ้าหาไม่เจอปุ่ม "เลือกไฟล์เอง" จะช่วยได้ทันที

ถ้ายังไม่เชื่อม MT5 ระบบใช้ข้อมูลฟรี COMEX (GC=F) อัตโนมัติ — วิเคราะห์ไม่หยุด
