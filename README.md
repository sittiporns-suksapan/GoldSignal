# GoldSignal — ผู้ช่วยวิเคราะห์ & เทรดทอง (XAU/USD)

แอป macOS (DMG) สำหรับเทรดทองผ่าน **MetaTrader 5** — วิเคราะห์ตลาดทุก 10 วินาที (ปรับได้ 5–60 วิ) ด้วย **ทีมเอเจนต์ 7 คน** + ระบบ plugin กลยุทธ์แบบเปิด
ส่งออร์เดอร์จริงได้เมื่อเปิดสวิตช์ (ปิดไว้ตั้งแต่แรก) • เข้าไม้/ปิดไม้อัตโนมัติ • ใช้งานผ่านเว็บจากมือถือได้ • แจ้งเตือน Telegram

> ⚠️ สัญญาณทั้งหมดเพื่อการศึกษาและช่วยตัดสินใจ **ไม่ใช่คำแนะนำการลงทุน** ทองคำ/CFD มีความเสี่ยงสูง ทดสอบบนบัญชี Demo ก่อนใช้เงินจริง

> 🛠 **นักพัฒนา / ติดตั้งเครื่องใหม่:** ดู [doc-dev.md](doc-dev.md) — clone, build DMG, ติดตั้ง EA, ย้ายข้อมูล, เว็บ/tunnel/ลิงก์ถาวร, Telegram, backtest, ปล่อยเวอร์ชัน

## กฎความเสี่ยงที่ล็อกไว้ในโค้ด (plugin แก้ไม่ได้)

| กฎ | ค่า |
|---|---|
| ทุกไม้ต้องมี Stop Loss | ไม่มี SL / SL ผิดฝั่ง = ปฏิเสธ • **แก้ไม้ภายหลังก็ลบ SL ไม่ได้** |
| ความเสี่ยงต่อไม้ | ล็อตคำนวณให้ขาดทุน ≤ % ที่ตั้ง — **เพดานสัมบูรณ์ 2% ของทุนจริง** (จาก equity MT5 แปลงเป็น USD) |
| ขยับ SL ไกลขึ้น | ต้องไม่เกินเพดาน 2% (ขยับเข้าใกล้ = ลดความเสี่ยง ทำได้เสมอ) |
| Risk:Reward ขั้นต่ำ | ตั้งต้น 1:1.5 (พื้นบังคับ 1:1) |
| ล็อตขั้นต่ำ 0.01 | SL กว้างจนล็อตต่ำกว่านี้ = ปฏิเสธ (ทุนเล็กจะเจอบ่อย — ตั้งใจให้เป็นแบบนี้) |
| โควตาต่อวัน | ปรับได้ (สัญญาณ + คำสั่งจริงนับรวม) + คูลดาวน์สัญญาณเดิม 15 นาที |
| มติสภา (โหมดเข้ม) | สวนมติ / ไม่มีมติ = ไม่อนุญาตเข้าไม้ |
| โหมดหยุดข่าว | วิเคราะห์ต่อ แต่ไม่ปล่อยสัญญาณใหม่ — เปิดเองก่อน Fed/NFP/CPI |

### เกตส่งออร์เดอร์จริง 3 ชั้น (ปิดหมดตั้งแต่แรก)

1. **ปุ่ม AutoTrading ใน MT5** (Ctrl+E) ต้องเขียว
2. **EA input `AllowOrders = true`**
3. **สวิตช์ "ส่งออร์เดอร์จริง" ในแอป** (+ ยืนยัน 2 ชั้นต่อไม้ เมื่อปิด "เข้าอัตโนมัติ")

ข้อมูลต้องสดเสมอ: bridge ≤15 วิ, ราคา ≤5 วิ, รอบวิเคราะห์ ≤20 วิ — ไม่สดเกินนี้ไม่ส่งคำสั่ง • ผลจาก MT5 แจ้งกลับจริง (ticket / retcode)

## แหล่งข้อมูลราคา

1. **MT5 ในเครื่อง (หลัก)** — EA `mt5-ea/JsonBridgeEA.mq5` (รุ่น 1.8) เขียนราคาทุกทิค + แท่งเทียน/บัญชี/ไม้ทุก ~3 วิ ลงโฟลเดอร์ `MQL5/Files`
   (`goldsignal_quotes.txt`, `goldsignal_bridge.json`, `goldsignal_commands.txt`, `goldsignal_results.txt`)
2. **ข้อมูลฟรี COMEX GC=F (สำรอง)** — ใช้อัตโนมัติเมื่อ MT5 ไม่พร้อม (วิเคราะห์ได้ แต่ส่งออร์เดอร์ไม่ได้)

เลือกที่มุมขวาบน: *อัตโนมัติ (MT5 → ฟรี)* / *MT5 เท่านั้น* / *ฟรีเท่านั้น*

### ติดตั้ง EA (ครั้งเดียว)

1. เปิดแอป → แท็บ **MT5** → **ติดตั้ง EA ให้ฉันเอง** (คัดลอก + คอมไพล์ให้)
2. ใน MT5 ลาก `JsonBridgeEA` ลงชาร์ต XAUUSD → Inputs: `AllowOrders = true` (ถ้าจะส่งไม้จริง) → Ctrl+E
3. การ์ด "สถานะการเชื่อม MT5" ต้องขึ้นเขียวภายใน 10 วิ (หาไฟล์ไม่เจอ → "เลือกไฟล์ goldsignal_bridge.json เอง")

> อัปเดต EA แล้วต้อง **ถอดออกจากชาร์ตแล้วลากใหม่** MT5 ถึงโหลดรุ่นใหม่

## ส่งคำสั่ง และปิดอัตโนมัติ (การ์ด "ส่งคำสั่ง")

- **ซื้อ/ขาย** ล็อต + SL/TP (เว้นว่าง = คิดจาก ATR ให้) • **ตารางไม้ที่เปิด**: กำไร-ขาดทุนสด • ปุ่ม **แก้** (SL/TP) / **ปิด** • **ปิดทุกไม้**
- **คำสั่งรอ** BUY/SELL LIMIT/STOP • ปุ่ม **แก้** (ราคาเข้า/SL/TP) / **ยกเลิก**
- **เข้าอัตโนมัติ** (สวิตช์): ไม้ที่ผ่านทุกเกตจะถูกส่งเองทันที — ทำงานต่อแม้ปิดหน้าต่าง
- **ปิดอัตโนมัติ** (ดูราคาสดทุกทิค มีแถบความคืบหน้าถึงเป้า):

| กลุ่ม | สวิตช์ | ทำงานเมื่อ |
|---|---|---|
| 💰 เก็บกำไร | ปิดทุกไม้ เมื่อกำไรรวม ≥ X | กำไรลอยตัวรวม (สกุลเงินบัญชี) ถึงเป้า |
| | ปิดทุกไม้ เมื่อจุดรวม ≥ N | จุดของทุกไม้รวมกัน (+200 กับ +100 = 300) |
| | ปิดเฉพาะไม้ที่บวก ≥ N จุด | ปิดเฉพาะไม้นั้น (XAUUSD 1 จุด = 0.01) |
| 🛡 ตัดขาดทุน | ปิดทุกไม้ เมื่อขาดทุนรวม ≥ X | ตรวจก่อนเป้ากำไรเสมอ |

> ระบบอัตโนมัติทำงานเฉพาะตอนแอป + MT5 เปิดอยู่ — SL/TP ของแต่ละไม้ที่เซิร์ฟเวอร์โบรกเกอร์ยังป้องกันอยู่เสมอ

## จุดรอเข้า (Entry Zones) และไม้เสมือน

- **จุดเข้าซื้อ** = แนวรับใกล้สุดใต้ราคา (หรือ Bollinger ล่าง M15) ±0.4×ATR • **จุดเข้าขาย** = แนวต้านใกล้สุดเหนือราคา ±0.4×ATR
- สถานะ: `รอ` / `🎯 ถึงจุดแล้ว` (แจ้งเตือน) / `ยกเลิก` / `ห้าม`
- ราคาแตะโซน = เปิด **ไม้เสมือน** อัตโนมัติ (ฝั่งละ 1 ไม้) เพื่อวัดว่าโซนแม่นไหม — จบเมื่อถึง TP / SL / ครบ 4 ชั่วโมง • **ไม่ใช่เงินจริง**

### เส้นบนกราฟ

| เส้น | ความหมาย |
|---|---|
| เหลือง / น้ำเงินโค้ง | EMA20 / EMA50 |
| เขียวหนา "รับ" / ทอง-แดง "ต้าน" | แนวรับ / แนวต้านจาก swing (แดงหนา = ชิดมาก) |
| เขียว/ทองโปร่ง "รอซื้อ/รอขาย" | ขอบโซนจุดรอเข้า |
| จุดไข่ปลาจาง | ขอบ Bollinger M15 |

## ทีมเอเจนต์ (Agent Council v3)

ทุกกฎผ่านการวัดย้อนหลังทอง 5m 60 วัน (ไม่มี lookahead) แยกครึ่งแรก/ครึ่งหลัง และ **เก็บเฉพาะสัญญาณที่บวกทั้งสองครึ่ง** — สัญญาณที่วัดแล้วติดลบถูกถอดออก (ไล่ CHoCH, ไล่โมเมนตัม, ซื้อย่อ EMA, เด้งแนวรับเปล่า ๆ)

| เอเจนต์ | ฝ่าย | ความเชี่ยวชาญ |
|---|---|---|
| ดีดกลับ (น้ำหนัก 1.4) | สัญญาณ | แท่ง M5 หลุดขอบ Bollinger แล้วปิดกลับเข้า • %B M15 หลุดขอบ / RSI สุดขั้ว ในตลาดออกข้าง • ยับยั้งการไล่ราคา |
| โครงสร้างแท่ง (1.3) | สัญญาณ | บันได HH+HL / LH+LL บน M15 • ทะลุสวนโครงสร้าง = มองเป็นการทะลุหลอก |
| เทรนด์ (1.2) | สัญญาณ | EMA H1+M15 ทางเดียวกัน **และ** โครงสร้าง M15 ยืนยัน • วัดความสะอาดด้วย Efficiency Ratio |
| โมเมนตัม (0.7) | สัญญาณ | แรงวิ่งเกิน 1×ATR ใน 40 นาที มักคืนกำไร (ไม่ไล่แท่ง) |
| สภาพตลาด | บริบท | วิ่งทางเดียว vs ออกข้าง (ER) + เปอร์เซ็นไทล์ ATR → ปรับน้ำหนักเพื่อน • ยับยั้งตลาดเงียบ/ผันผวนสุดขั้ว |
| ช่วงเวลา | บริบท | ลอนดอน = ลดสายสวน • ทับ NY = ทุกสาย • บ่าย NY/ดึก = ลดโครงสร้าง • ชั่วโมงแรกหลังเปิดตลาด |
| ระดับราคา | บริบท | มติที่วิ่งชนแนวใกล้ (≤0.5×ATR) ได้แรงเสริม (วัดแล้วแนวใกล้มักแตก) |

- **ประธานสภา:** น้ำหนักจริง = ฐาน × ผลงานจริง (SkillBook 0.6–1.5) × ตัวปรับจากฝ่ายบริบท → เห็นพ้อง ≥ 3 (ปรับ 2–6) → มติ + ความมั่นใจ
- **SkillBook:** โหวตที่มั่นใจ ≥50% ถูกตรวจผลหลัง 30 นาที → อัตราชนะรายเอเจนต์ปรับน้ำหนักอัตโนมัติ (เก็บใน `agent-skills.json`)
- การ์ดทีมเอเจนต์แสดงเหตุผลของทุกคน + ตัวปรับน้ำหนักตามสนาม + แรงเสริม/สิทธิ์ยับยั้ง

### ผล Backtest (5m GC=F 60 วัน, มี spread + slippage, โดน SL ก่อนเมื่อปะทะพร้อม TP)

รันเอง: `node scripts/backtest.js --refresh` • ผลบันทึกที่ `backtest-report.json`

| ทีม (โหมดเข้ม, มติ ≥70%) | ไม้ | ชนะ | รวม R | PF |
|---|---|---|---|---|
| v2 (เดิม, หลังแก้บั๊ก lookahead) | 114 | 32% | −8.21 | 0.90 |
| **v3 (ปัจจุบัน)** | **64** | **39%** | **+10.54** | **1.25** |
| v3 ที่มติ ≥60% | 96 | 39% | +14.39 | 1.22 |

- สภายับยั้งสัญญาณสวนมติ 182 ใบ — ถ้าปล่อยผ่านรวม −15.92 R
- ⚠ backtest รุ่นก่อน v3 เคยใช้แท่ง M15/H1 ที่รวมราคาอนาคต (แก้แล้ว) ตัวเลขเก่าใน commit ก่อนหน้าจึงสูงเกินจริง
- ⚠ ประวัติย้อนหลังไม่การันตีอนาคต — อัตราชนะ ~39% แพ้ติดกัน 5–6 ไม้เป็นเรื่องปกติ

## เว็บควบคุมเต็ม (ใช้จากมือถือ / ที่ไหนก็ได้)

แท็บ **MT5** → การ์ด **แผงระยะไกล**

1. **ตั้งรหัสผ่านเว็บ** (≥8 ตัว) — ทุกช่องทางใช้รหัสเดียวกัน
2. เครื่องนี้: `http://localhost:8008` • เปิดสวิตช์ "เข้าจากนอกเครื่อง" = ใช้ผ่าน Wi-Fi / Tailscale ได้
3. **Tunnel → port 8008:** cloudflared (ฟรี ลิงก์เปลี่ยนทุกครั้ง) / ngrok / Tailscale Funnel (ลิงก์ถาวร)
4. **ลิงก์ถาวร GitHub Pages:** ใส่ repo แยก (เช่น `owner/goldsignal-link`) → แอปอัปเดตที่อยู่ tunnel ล่าสุดให้เอง
5. ทุกลิงก์มีปุ่ม **คัดลอก / เปิด** • ซ่อนแผงได้ (ยังเห็นสถานะย่อ + ปุ่มคัดลอกลิงก์ถาวร)

ความปลอดภัย: ทุกหน้าต้องล็อกอิน • ผิด 5 ครั้ง/IP = ล็อก 15 นาที • คำขอผ่าน tunnel ไม่นับเป็นเครื่องนี้ • ตั้งรหัส/tunnel/Telegram ได้จากแอปบนเครื่องเท่านั้น • คำสั่งจากเว็บผ่านเกตความเสี่ยงชุดเดียวกับแอป และจด IP ลง log

> ⚠ เว็บนี้กดซื้อ/ขาย/ปิดไม้จริงได้ — ใช้รหัสยาว เดายาก และไม่บอกใคร

## แจ้งเตือน Telegram

แท็บ **MT5** → การ์ด **แจ้งเตือน Telegram**: @BotFather `/newbot` → วาง token → กด Start ในแชต bot → **หา chat id** → เปิดสวิตช์ → **ส่งทดสอบ**

เลือกแจ้งได้ทีละเรื่อง: ไม้จริงเข้า • ไม้จริงปิด (TP/SL/ปิดเอง/อัตโนมัติ + กำไร-ขาดทุนจริง เงิน + จุด) • เข้า/ปิดอัตโนมัติ • คำสั่งล้มเหลว • คำสั่งรอ • สัญญาณ • ไม้เสมือน • ระบบ (MT5 หลุด / tunnel ล่ม)

token เก็บในเครื่องเท่านั้น (ไฟล์สิทธิ์ 600) หน้าเว็บมองไม่เห็น

```js
  description: 'อธิบายสั้น ๆ',
  strategy({ analysis, candles, price, ind, council }) {
    // analysis.bias: 'bull'|'bear'|'neutral' • analysis.tf.H1/M15/M5 ตัวเลขพร้อมใช้
    // candles.M5/M15/H1/M1 = แท่งเทียน {t,o,h,l,c,v} • council = มติสภารอบนี้
    const e20 = ind.lastNum(ind.ema(candles.M5.map((c) => c.c), 20));
    if (!e20 || price <= e20) return null;
    return { side: 'buy', sl: price - 6, tp: price + 15, confidence: 70, reason: 'ปิดเหนือ EMA20' };
  },
};
```

กด **โหลดใหม่** — plugin ที่พังไม่ทำให้ระบบล้ม (try/catch) • รองรับ `strategy()` แบบ async • สัญญาณที่ไม่มี SL ถูกต้องถูกกฎความเสี่ยงทิ้งเสมอ

## ข้อจำกัดที่ควรรู้

- ระบบอัตโนมัติ (เข้าไม้ / ปิดอัตโนมัติ / Telegram) ทำงานเมื่อแอป + MT5 เปิดอยู่ — พับฝาโน้ตบุ๊ก (ไม่ต่อจอนอก) เครื่องยังหลับ
- ทุนเล็กเทียบระยะ SL จะถูกปฏิเสธเกือบทุกไม้ (ล็อต 0.01 เสี่ยงเกิน 2%) — ตั้งใจให้เป็นแบบนี้
- ราคาฟรี GC=F เป็นฟิวเจอร์ส COMEX อาจต่างจากโบรกเกอร์เล็กน้อย — ใช้ MT5 เป็นหลัก
- ไม่มีปฏิทินข่าว — เปิดโหมดหยุดข่าวเองก่อนข่าวใหญ่
- DMG ไม่ได้เซ็นชื่อ — เปิดครั้งแรก: คลิกขวา → Open • build สำหรับ Apple Silicon (Intel ต้อง build เอง ดู [doc-dev.md](doc-dev.md))
