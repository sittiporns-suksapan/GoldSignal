# GoldSignal — ผู้ช่วยวิเคราะห์ & หาโอกาสเทรดทอง (XAU/USD)

แอป macOS แพ็กเป็น **DMG** สำหรับ trader ทอง โหมด **สัญญาณเท่านั้น (ไม่ส่งออร์เดอร์เอง)**
วิเคราะห์ตลาดตลอดเวลา ทุก 10 วินาที (ปรับได้ 5–60 วิ) พร้อม **ระบบ plugin กลยุทธ์แบบเปิด**

> ⚠️ สัญญาณทั้งหมดเพื่อการศึกษาและช่วยตัดสินใจ **ไม่ใช่คำแนะนำการลงทุน** ทองคำ/CFD มีความเสี่ยงสูง

---

## ความเสี่ยงถูกล็อคไว้ในโค้ด (แก้ไม่ได้แม้แต่ plugin)

| กฎ | ค่า |
|---|---|
| ทุกสัญญาณต้องมี Stop Loss | ไม่มี SL / SL ฝั่งผิดทิศ = ทิ้งทันที |
| ความเสี่ยงต่อไม้ | คำนวณล็อตให้ขาดทุน ≤ % ที่ตั้ง — เพดานสัมบูรณ์ 2% |
| Risk:Reward ขั้นต่ำ | เกณฑ์ตั้งต้น 1:1.5 (พื้นต่ำสุดบังคับ 1:1) |
| ล็อตขั้นต่ำ 0.01 | ถ้าพื้นที่ SL กว้างจนล็อตต่ำกว่านี้ = ปฏิเสธสัญญาณ |
| โควตาสัญญาณต่อวัน | ตั้งต้น 8 (ปรับได้) + คูลดาวน์สัญญาณเดิม 15 นาที |
| โหมดหยุดข่าว | เปิดแล้วระบบวิเคราะห์ต่อ แต่ไม่ส่งสัญญาณใหม่ |
| ไม่ส่งออร์เดอร์ | แอปไม่มีสิทธิ์เข้าไม้เองทุกกรณี — คุณตัดสินใจเทรดบน MT5 เอง |

---

## แหล่งข้อมูลราคา

1. **MT5 ในเครื่อง (หลัก)** — ผ่านไฟล์ bridge ที่ EA (`mt5-ea/JsonBridgeEA.mq5`) เขียนทิ้งไว้ทุก 3 วินาที ติดตั้งครั้งเดียวดูหัวข้อด้านล่าง
2. **ข้อมูลฟรี COMEX GC=F (สำรอง)** — ต่ออัตโนมัติเมื่อ MT5 ยังไม่พร้อม ไม่ต้องมีบัญชี ไม่มีค่าใช้จ่าย

เลือกพฤติกรรมได้ที่หัวมุมขวาบน: *อัตโนมัติ (MT5 → ฟรี)* / *MT5 เท่านั้น* / *ฟรีเท่านั้น*

## จุดรอเข้า (Entry Zones) — รอถึงจุดค่อยเข้า

ระบบคำนวณ **โซนราคาที่ควรรอ** ทั้งสองฝั่ง + ติดตามสด:

- **จุดเข้าซื้อ** = แนวรับใกล้สุดใต้ราคา (หรือ Bollinger ล่าง M15) ±0.4×ATR — รอราคา**ดีดลงเข้าโซน**
- **จุดเข้าขาย** = แนวต้านใกล้สุดเหนือราคา (หรือ Bollinger บน) ±0.4×ATR — รอราคา**พุ่งเข้าโซน**
- สถานะ 4 แบบ: `รอ` (แสดงระยะห่าง $ สดทุกทิค) / `🎯 ถึงจุดแล้ว` (ราคาเข้าโซน → **แจ้งเตือน macOS**) / `ยกเลิก` (เทรนด์สวน หรือช่วงเวลาไม่แนะนำ) / `ห้าม` (ราคาหลุดใต้โซน = มีดตก / ทะลุเหนือโซน = ไล่ขาย)
- โซนแสดงบนกราฟเป็นแถบโปร่ง: เขียว = โซนซื้อ, ทอง = โซนขาย

## เส้นบนกราฟอ่านว่าอย่างไร

| เส้น | ความหมาย |
|---|---|
| เส้นเหลือง/น้ำเงินโค้ง | EMA20 / EMA50 ของไทม์เฟรมที่แสดง |
| เขียวเส้นหนา + label "รับ" | แนวรับจากจุดกวีนดั่ง (swing low) |
| ทอง/แดง + label "ต้าน" | แนวต้าน (แดงหนา = ราคาใกล้มาก → ❗ห้ามไล่ซื้อ) |
| เขียว/ทอง **โปร่ง** + "รอซื้อ/รอขาย" | **ขอบโซนจุดรอเข้า** (Entry Plan) |
| จุดไข่ปลาจางบน/ล่างสุด | ขอบ Bollinger M15 |
| เส้นประขาวเฉียง | crosshair (โชว์เวลา/ราคาตามเมาส์) |

## ปุ่มซื้อ/ขายจริง + บัญชีจริง (v1.1.0 ในการ์ด "คำสั่งซื้อขาย")

คุมจริงด้วยเกต 3 ชั้น **ที่ปิดหมดตั้งแต่แรกเสมอ**:
1. **ปุ่ม AutoTrading ใน MT5** (Ctrl+E) — เหลือง/แดง = ระบบส่งไม้อะไรไม่ได้เลย
2. **EA inputs: AllowOrders = true** — ประตูฝั่ง EA
3. **สวิตช์ "อนุญาตส่งออร์เดอร์จริง" ในแอป** + ยืนยัน 2 ชั้นต่อไม้

ตามข่าว: **SL ห้ามลบ** • **เพดานความเสี่ยง 2% ของทุนจริง** (จาก MT5 balance/equity จริง, ผู้ใช้ตั้งทุนไม่จำเป็นอีกเมื่อเชื่อม) • **โควตา 8/วัน** (สัญญาณ+คำสั่งนับรวม) • **มติสภาสวน = กีดกันโดยแย่งห้าม** • แจ้งผลจาก MT5 จริง (ticket/retcode)

- แถวบัญชีจริงส่งสดทุกทิค: ทุน / ทุนสุทธิ (Equity, แชนาลนี่ขาย/กำไรลอยตัว) / มาร์จิ้นคงเหลือ + ตำแหน่งเปิดทั้งหมดพร้อมปุ่มปิดทีละไม้
- เลนราคาเรียลไทม์: EA เขียนราคาจาก **OnTickของMT5** แก้ทิค (~1-4 ครั้ง/วิ) + แอป fs.watch รับเหตุการณ์ → บทหน่วงรวม ~0.3-0.5 วิ เต้มรูป MT5
- เทียบ: ราคาทุ่ก 3-4 วิ (แท่ง) + วิเคราะห์ทุกทิคเห็นแท่งใหม่หลังไม่ช้าผ่านเหตุการณ์ (~1 วิ หลังแท่งใหม่)
- ไฟล์ทั้งหมดหน้าเรียวไทม์ปลูกปากใน "MQL5/Files" ของโบรเกอร์: `goldsignal_quotes.txt` / `_bridge.json` / `_commands.txt` / `_results.txt`

## ติดตั้ง MT5 Bridge (ครั้งเดียว ~2 นาที)

1. เปิด **MetaTrader 5** → ล็อกอินบัญชี → กด **F4** เปิด MetaEditor
2. Navigator → คลิกขวา **Experts** → **Open Folder** → วางไฟล์ `mt5-ea/JsonBridgeEA.mq5` (มากับ DMG นี้)
3. เปิดไฟล์ใน MetaEditor → กด **Compile (F7)**
4. กลับ MT5 → ลาก `JsonBridgeEA` ไปวางบนชาร์ตทอง (XAUUSD/GOLD ชื่อไหนก็ได้) → กด OK
   - EA นี้**ไม่ส่งออร์เดอร์** จึงไม่ต้องเปิด AutoTrading
5. ในแอป แท็บ **เชื่อม MT5** สถานะต้องขึ้นเขียวภายใน 10 วิ
   ถ้าแอปหาไฟล์ไม่เจอ ให้กด **"เลือกไฟล์ goldsignal_bridge.json เอง"** แล้วชี้ไปที่ไฟล์ที่ EA สร้างไว้ (อยู่ในโฟลเดอร์ `MQL5/Files` ของ MT5)

## ทีมเอเจนต์ (Agent Council v2) — แต่ละคน "เก่งเฉพาะด้าน + วัดผลงานตัวเองได้"

ก่อนสัญญาณใดถึงมือคุณ เพเจนต์ 7 ฝ่าย โหวตสดทุก 10 วินาที (รันในเครื่อง, เร็วมิลลิวินาที):

| เอเจนต์ | สกิลเฉพาะด้าน (รายละเอียดเพิ่มใน v2) |
|---|---|
| เทรนด์ | โครง EMA 2 ชั้น **+ วัดความแรงเทียบ ATR + วัด "ยืดปลายคลื่น"** (เทรนด์ยืดวิ่งเลขคิววีต้องอ่านแผนเงียบ) |
| โมเมนตัม | ROC 8 แท่ง + EMA9/21 + RSI + **อ้าอาการหมดแรง (ท้ายแรงลด ลดพุดลับขาว)** |
| ดีดกลับ | RSI + **%B ขอบ Bollinger (ทะลุขอบจริง)** + **ไส้เทียนปฏิเสธยาว (wick rejection)** + สิทธิ์ยับยั้งไล่ราคา |
| โครงสร้างแท่ง | **Market Structure แบบ SMC จริง: ลำดับจุดกวีน + BOS (หลักแหลม) + CHoCH (สภาพพลิกโครง)** |
| สภาพตลาด | **เปอร์เซ็นไทล์ ATR เทียบ 200 แท่ง M15** (ตลาดเงียบ/ปกติ/สุดระเบิด) + สิทธิ์ยับยั้งทั้งสองขั้ว |
| ช่วงเวลา | เซสชัน + **กี่ชั่วโมงแรกหลังเปิดตลาด + ชม.หุ้น NY เปิด 15:30 ระวังเผวียเวลา** |
| ระดับราคา | **นับโซนทับซ้อน (confluence): SUP + BB + ระดับใกล้ตัวทับกัน ≥2 ชั้น → โหวตแรงขึ้น** |

### สมุดปูมสกิล (SkillBook) — "เก่ง" วัดผลได้ ไม่ใช่คำโฆษณา

- ทุกโหวตที่มั่นใจ ≥50% ถูกจดไว้ → **หลัง 30 นาที** ตรวจราคา: เดินตามโหวต ≥0.5×ATR = ชนะ, ย้อนก่อน = แพ้, เด้งไม่ชัด = ไม่นับ
- **น้ำหนักในสภาปรับอัตโนมัติ ×(0.6–1.5) ตามอัตราชนะของเอเจนต์แต่ละคน** — ใครเก่งด้านตัวเองจริงจะยิงน้ำหนักมากกว่าคนที่แตะน้อย
- ผลงานเก็บลงดิสก์ (`agent-skills.json`) — รีสตาร์ทไม่หาย, แสดงในหน้าจอ: "ผลงาน: ยอดเยี่ยม 68% (22 ไม้)"
- ตัวอย่างแท็ก: เอเจนต์ใหม่ยังไม่มีผลงาน = น้ำหนักปกติ; เกลา 8 ไม้ตัวอย่างขึ้นไปจึงเริ่มคุมคะแนน

### มติ = ประตูซื้อขาย (แนะนำจาก backtest 60 วัน)

- ประธานสภา: น้ำหนัก (ฐาน × สกิล) → เห็นพ้อง ≥3 (ปรับ 2–6 ได้) → มติทิศ + ความมั่นใจ
- **โหมดเข้ม (ตั้งต้น)**: สัญญาณ/ปุ่มซื้อขายจริง ต้องได้ "มติสภาสนับสนุน" อย่างน้อยแยกไม่มีมติ → สวนมติ/ไร้มติ = กรองพร้อมเหตุผล
- เพดานมติอนยล่าง "มติสภา" ออกไม้ = 70% (ผล: +19.89R / PF 1.23 จากข้อมูล 60 วัน)

### หลักฐานจาก Backtest ข้อมูลจริง 60 วัน (5m GC=F, พร้อมต้นทุน spread+slippage, โดน SL ก่อน TP เมื่อปะทะพร้อมกัน)

รันเองได้: `node scripts/backtest.js --refresh` | ดูไฟล์ผล: `backtest-report.json`

| เพดานมติสภา | ไม้ (เข้ม) | ชนะ% | รวมR | PF |
|---|---|---|---|---|
| 80 | 0 | — | 0 | — |
| 75 | 78 | 35% | +0.66 | 1.01 |
| **70 (ค่าตั้งต้น)** | **134** | **39%** | **+19.89** | **1.23** |
| 65 | 147 | 38% | +18.36 | 1.19 |

- ในโหมดเข้ม: ดีดกลับตามเทรนด์ +2.54R (ชนะ 67%, PF 3.26) มติสภา +19.89R (ชนะ 39%, PF 1.23)
- สภายับยั้ง 221 สัญญาณ ถ้าปล่อยผ่านจะแพ้รวม **-43.86R** (ชนะแค่ 31%) → วีโต้ของทีมพิสูจน์แล้วกรองไม้แพ้ได้จริง
- จากหลักฐานนี้ **ค่าตั้งต้นของแอป: โหมดเข้มเปิด + ปลุกไม้ออกเมื่อมติ ≥70% + ปิดกลยุทธ์ "บีบแบนด์" และ "โมเมนตัม"** (เปิดกลับได้ในแท็บ PLUGINS)
- ⚠ ประวัติย้อนหลังไม่การันตีอนาคต — ตัวเลขคือภาพสถิติ 60 วันล่าสุด และการจูนเพดานทำในชุดเดียวกัน (in-sample) จึงควรเฝ้าดูผลจริงต่อเนื่อง

## กลยุทธ์ในตัว

| Plugin | หลักการ | ค่าตั้งต้น |
|---|---|---|
| ดีดกลับตามเทรนด์ | เทรนด์ M15/H1 ชัด → รอดีดเข้า EMA20 + RSI สวนขั้ว | เปิด |
| มติทีมเอเจนต์ | สภาเห็นพ้อง ≥75% → เข้าตามมติทีม SL ยึดโครงสร้าง | เปิด |
| บีบแบนด์ทะลุ | Bollinger squeeze → ทะลุขอบ M5 | ปิด (แพ้ใน backtest) |
| โมเมนตัมหักเข้าเทรนด์ | EMA9 ตัด EMA21 + แท่งแรง | ปิด (แพ้ใน backtest) |

**เพิ่มกลยุทธ์ของคุณเอง:** แท็บ PLUGINS → "เปิดโฟลเดอร์ plugins ของผม" → สร้างไฟล์ `.js`:

```js
module.exports = {
  id: 'my-strategy',
  name: 'กลยุทธ์ของผม',
  description: 'อธิบายสั้น ๆ',
  strategy({ analysis, candles, price, ind }) {
    // analysis.bias: 'bull'|'bear'|'neutral', analysis.tf.H1/M15/M5 ตัวเลขพร้อมใช้
    // candles.M5/M15/H1/M1 = แท่งเทียน {t,o,h,l,c,v}
    // ind = ema, rsi, atr, bollinger, swings, aggregate ...
    // ตัวอย่าง:
    const e20 = ind.lastNum(ind.ema(candles.M5.map(c => c.c), 20));
    if (!e20 || price <= e20) return null;
    return { side: 'buy', sl: price - 6, tp: price + 15, confidence: 70, reason: 'ปิดเหนือ EMA20' };
  },
};
```

กลับมาแท็บ PLUGINS กด **โหลดใหม่** — plugin ที่เขียนผิดพลาดจะ**ไม่ทำให้ระบบล้ม** (ถูก wrap ใน try/catch) และสัญญาณไหนไม่มี SL ที่ถูกต้องจะถูกทิ้งโดยกฎความเสี่ยงเสมอ

## สั่งจากซอร์สโค้ด

```bash
npm install          # ติดตั้ง dependency
npm run smoke        # ทดสอบ engine/กฎ/connector (SMOKE_NETWORK=1 เพื่อทดสอบต่อ Yahoo จริง)
npm start            # รัน dev mode
npm run dist         # สร้าง DMG → dist/GoldSignal-1.0.0-arm64.dmg
node scripts/make-icon.js   # แก้ไอคอน (build/icon.png → build/icon.icns ผ่าน iconutil)
```

> ไฟล์ DMG **ไม่ได้เซ็นโค้ด** (ประหยัดค่า Apple Developer) — เปิดครั้งแรก: คลิกขวาที่ **GoldSignal.app → Open → Open** หรืออนุญาตใน System Settings → Privacy & Security

## โครงโปรเจกต์

```
src/main/          Electron main + preload (IPC, window, settings)
src/engine/        หัวใจระบบ (ไม่พึ่ง Electron — ทดสอบด้วย node ล้วน)
  indicators.js    EMA/RSI/ATR/Bollinger/Swings/Aggregate
  analysis.js      วิเคราะห์หลายไทม์เฟรม → bias, squeeze, S/R
  council.js       ทีมเอเจนต์ 7 ฝ่าย + ประธานสภา + ด่านอนุมัติสัญญาณ
  risk.js          กฎความเสี่ยงถาวร + คำนวณล็อต
  engine.js        วนวิเคราะห์ → dedupe/คูลดาวน์/โควตา → snapshot
  plugins.js       โหลดกลยุทธ์ (sync/async) + ป้องกัน crash
  connectors/      mt5.js (ไฟล์ bridge), yahoo.js (ฟรี)
plugins/           กลยุทธ์ในตัว 4 ตัว (เปิด/ปิดผ่าน UI)

renderer/          UI ไทย (ชาร์ต, สัญญาณ, ทีมเอเจนต์, ตั้งค่า, บันทึก)

```

## ทิปสำหรับความแม่นยำ

- ป้ายไม้อยู่แค่หมายเลขในบัตรสัญญาณ — หากแก้กลยุทธ์/ค่าเกณฑ์ให้ **รัน backtest ซ้ำทุกครั้ง** (`node scripts/backtest.js`) อย่าปรับตามแวบแรกโดยไม่วัด
- ตั้ง quorum สูงขึ้น (4–6) = สัญญาณน้อยลงแต่ทิมมากขึ้น; ลด councilMin ต่ำลง = สัญญาณถี่ขึ้นแต่คุณภาพตก (อย่าลดต่ำกว่า 65)
- แนะนำเริ่มจากกลยุทธ์ในตัวสองตัวที่เปิดไว้ก่อน อย่าเปิดทั้งหมดพร้อมกัน
- เพิ่มเอเจนต์ AI/LLM ภายหลังได้: ระบบ plugin รองรับ `strategy()` แบบ async — ใช้ API key ของคุณ แต่จะช้ากว่าเอเจนต์นี้มาก (ควรใช้เป็นเอเจนต์รายพระอิริยะ ไม่ใช่ทุก tick)

## ข้อจำกัดที่ควรรู้

- ราคาฟรี (GC=F) เป็นสัญญาฟิวเจอร์ส COMEX เทียบเคียง spot ได้แต่อาจต่างเล็กน้อยจากโบรกเกอร์คุณ — ใช้ MT5 เป็นหลักเมื่อพร้อม
- ล็อตแนะนำคิดจากสัญญามาตรฐาน **100 ออนซ์/ล็อต** (XAUUSD ทั่วไป) — ตรวจ spec ของโบรกเกอร์คุณ ถ้าต่างให้ปรับทุน/% เสี่ยงตาม
- ระบบไม่รู้จักปฏิทินข่าวเอง — ใช้โหมด "หยุดข่าว" เองก่อนข่าวใหญ่ (Fed/NFP/CPI)
